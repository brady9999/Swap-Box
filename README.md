## What is Swap-Box
Swap-box was used as a GUI to convert ```show run``` files from a old Cisco switch to match an upgraded template for newer models then converts them to YAML for ansible read.

## To Install Run The Following Command (Change Path To Match Your Directory)

```powershell
cd /path/SwapBox
git clone https://github.com/brady9999/Swap-Box.git
python3 -m http.server 8080
```
**Needs Ollama to be Installed**

Code will need to be modified since it was used just for a single test VM
